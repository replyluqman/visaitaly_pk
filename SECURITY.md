# Security policy

## Reporting a vulnerability

Email **replyluqman@gmail.com** with the subject `SECURITY: VisaItaly PK`.
Do not open a public issue.

Please include the affected endpoint or screen, steps to reproduce, and impact.
Do not access, change or keep other users' data beyond what is needed to show the issue.

| Step | Target |
|---|---|
| Acknowledgement | within 3 working days |
| Initial assessment | within 7 working days |
| Fix for a confirmed high-severity issue | as fast as possible; you will be kept informed |

## Scope

The VisaItaly PK Android app, its API (`/v1/*`), and the admin CMS.
Out of scope: Firebase, Cloudflare, Neon and Google Play infrastructure (report
to those vendors), denial-of-service, social engineering.

## Supported versions

Only the latest production release of the app and API receive fixes.

Engineering security rules for contributors: `docs/SECURITY.md`.

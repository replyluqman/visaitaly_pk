# 0006 — Unauthorised access returns 404, never 403
Status: Accepted | Date: 2026-09

## Context
A 403 for another user's id confirms the row exists — an enumeration oracle.

## Decision
Every user-owned query filters by `user_id` in the SQL `WHERE`. A miss — absent or
not yours — is `NOT_FOUND`. No fetch-then-check in application code.

## Consequences
- Integration Gate 3 must include a cross-user test for every id-taking route.
- 403 is reserved for state the caller is entitled to know about:
  `USER_DELETED`, `LEGAL_ACCEPTANCE_REQUIRED`, `APPLICANT_READ_ONLY`.

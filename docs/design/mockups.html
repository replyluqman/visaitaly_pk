VisaItaly PK, glass-lite mockups

Reference for DESIGN-SYSTEM.md. Blur only on bars, nav, hero, sheets. Lists use tint.

  • Low-tier devices (lite): blur is removed everywhere and glass becomes tint. solid: no mesh and no blur.
  • The palette avoids the Italian tricolour and crests on purpose, so the app never reads as official (PRD §18).
  • Emoji icons are placeholders. Production uses a single outline icon set (e.g. Lucide / Phosphor).

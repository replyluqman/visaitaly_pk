# Screenshots (generated)

Rendered from the real widgets and the real theme by `apps/mobile/test/screenshots/screenshots_test.dart` — **not** from a device:

```
cd apps/mobile && SCREENSHOT_DIR=../../docs/design/screenshots flutter test test/screenshots
```

- 1080×2340 px (a typical 360×780 dp Android at 3×), Inter and Material Icons loaded.
- **All names, titles and numbers are invented** for illustration; nothing here comes from the API or the CMS.
- Light/dark, the `full` glass tier (blur on the app bar, bottom bar and the dashboard hero) and the `solid` tier (03) are shown.
- This is a software rasteriser: blur, shadows and anti-aliasing can differ slightly from a real GPU. It does not replace a device pass (see `docs/LAUNCH-CHECKLIST.md`).
